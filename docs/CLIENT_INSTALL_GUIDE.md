# Boba Tiger Hours Tracker — Setup Guide

Welcome! Here's everything you need to get up and running.

## 1. What You'll Receive

You'll get a file that looks like **"Boba Tiger Hours Tracker Setup 1.0.0.exe"** (or a similar version number). Your manager might send it to you via email, USB stick, or a download link — however works for them. That's the installer.

## 2. Installing It

This is the easy part:

1. Double-click the .exe file you received
2. The installer wizard will open — just click **Next** through the steps
3. When it asks where to install: the default location is fine, keep clicking **Next**
4. When it asks about adding desktop and Start Menu shortcuts: **leave those checked** (makes it easier to find later)
5. Click **Install**
6. Click **Finish** — you're done!

## 3. First Run: That Blue Security Warning

The first time you try to open the app, you'll probably see a blue screen from Windows that says something like "Windows protected your PC." **This is completely normal and not a virus.**

Since the app is brand new, it's not yet registered with Microsoft (that costs money and takes time), so Windows shows this warning as a heads-up. It's just doing its job. Here's what to do:

1. Click **"More info"** on that screen
2. Click **"Run anyway"** at the bottom

That's it — the app will open.

**Why it's safe:** This app only keeps your data on your own computer. It never sends anything to your manager, to Boba Tiger head office, or to any company — it's completely local. The only exception: if you choose to add an AI helper in the welcome screen, it can send data to that service, but that's totally optional and you control it.

## 4. Welcome Wizard (First Time Only)

When you open the app for the first time, you'll see a quick welcome screen with three steps:

1. **Welcome intro** — just a hello
2. **AI helper (optional)** — you can add a free AI key if you want, or skip it. Everything works either way
3. **Add staff names** — type in the team members who'll use this app

The whole thing takes under a minute. You can edit staff names later in Settings.

## 5. How Updates Work

The app checks for updates quietly in the background. If a new version is available, a popup will ask **"Download it now?"** — you can click "Not now" and keep working. Nothing happens without you.

Once downloaded, another popup asks if you want to restart now or do it later. No updates install themselves without your permission.

## 6. Your Data Stays Private

Everything — staff names, hours, all settings — stays only on this computer. There's no cloud, no backup to anyone else's server, no sending data anywhere.

**Backup:** If you want to be extra safe, there's a **Backup** button in Settings that saves a copy you can keep somewhere. If something ever goes wrong, you can use **Restore** to bring it back.

## 7. If Something Goes Wrong

**Antivirus warnings:** Your antivirus software might also flag the installer the first time, for the same reason Windows does (#3 above). Same fix: it's safe, just let it through.

**App won't open:** Try restarting your computer and opening it again.

**Still stuck:** Contact (your manager) for help.
